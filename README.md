# metropolis_2026
## Inspiration
Als Inspiration für dieses Projekt diente der Film "Metropolis" von Fritz Lang aus dem Jahr 1927. Der Film spielt in einer futuristischen Stadt, die von einer strengen sozialen Hierarchie geprägt ist. Hierbei war der Fokus auf den hier gezeigten Postern, die die düstere und industrielle Atmosphäre der Stadt vermitteln.

![Alternativtext](https://tile.loc.gov/image-services/iiif/service:gdc:gdcwdl:wd:l_:04:31:6:wdl_04316:3_2_16301956/full/pct:12.5/0/default.jpg)

Das Ziel des Projekts war es, eine ähnliche Atmosphäre zu schaffen. Insgesamt wollte ich eine visuelle Darstellung schaffen, die die düstere und faszinierende Welt von "Metropolis" einfängt und das umgesetzt mit p5.js.
